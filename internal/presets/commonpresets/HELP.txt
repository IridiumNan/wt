=== Water-Repo (wt) - Help Manual ===

>>> Overview <<<

A lightweight personal/small-team package repository manager.

>>> Basic Usage <<<

-- Search for a package --

    wt search <package-name>

-- View package details --

    wt info <package-name>

-- Download a package --

    wt install <package-name>

-- Upload a local package --

    wt upload <path-to-package>

-- Replace an existing package --

    wt replace <package-name> <path-to-new-package>

-- Rename a package --

    wt mv <old-name> <new-name>

-- Delete a package --

    wt rm <package-name>

>>> Permission Management <<<

Three permission levels with token-based authentication:

- Read: search, list, info
- Install: download packages
- Write: upload, replace, rename, delete, tag

>>> Configuration Files <<<

Client config: ~/.config/water-repo/client_config.json
Server config: ~/.config/water-repo/server_config.json
